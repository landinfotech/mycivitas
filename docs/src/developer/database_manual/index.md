# Asset Database Model Manual

This manual documents the Asset Database, its underlying data model, and the supporting processes that make it operational. It provides a reference for technical staff responsible for maintaining, querying, and extending the system. The primary goal is to clarify how assets are represented, classified, and managed, ensuring consistency in both day-to-day operations and long-term development.

## Manual Overview

1. **Asset Data Concepts** - How assets are organized, classified, and their attributes stored.

2. **Data Model Overview** - Key tables, storage logic, and the mini-EAV approach for properties.

3. **Technician Views** - Simplified views for technicians, triggers, and row-level security.

4. **Data Exports & Reporting** - Materialized views and export datasets for reporting/planning.

5. **Data Model Updates** - How updates are handled and current versioning practices.

6. **Appendices** - ERD, table/column descriptions, and common SQL workflows.
