# Data Model Updates

## Update Procedure

Updates often involve re-running SQL scripts that drop, recreate, or modify tables and views. Scripts are stored in versioned folders for traceability.

## Versioning

Current versioning is informal: SQL scripts are kept in incrementally named folders on Google Drive. A formal database migration/versioning system is planned for the future.
